3. NUMERICAL METHOD AND VALIDATION  (waveguide.py; dev/waveguide_run_validate.log: 64/64 PASS)
-----------------------------------------------------------------------------------------------------
Block problem with K(z) = K_inf s6(z), s6 = (1 - e^{-12Hz})^{1/12}; the irrep is the sign of K_inf.
  - Pruefer angle p and ln r are integrated; p(0) = th + Pi/2 at the wall.
  - Asymptotic region: for z >= z_a = 3/H, K(z)/K_inf - 1 < 2e-17, so the decaying solution there is
    EXACTLY the eigenvector of the constant matrix (angle p_d(om)); no z_max ~ 1/kappa is needed, which
    makes shallow levels exact.
  - Mismatch Delta(om) = p_left(z_m) - p_right(z_m); levels <=> Delta = j Pi.  Delta is strictly decreasing
    in om (dp_left/dom < 0, dp_right/dom > 0), so the number of levels in the gap is exactly
    #{ j : Delta(+R) < j Pi < Delta(-R) }: a rigorous count that catches shallow levels.
  - Root search: for each sign of om the decay rate kappa runs over 0 plus an 80-point LOG grid from
    1e-10 R to R (om = +-Sqrt[R^2 - kappa^2]); Delta is scanned at a fixed matching point (pure backward
    shooting, stable in both allowed and forbidden regions); every j Pi crossing is refined by brentq in
    kappa with the matching point in the middle of the classically allowed region next to the wall
    (om^2 > m^2 + K(z)^2) when it exists, else at z_m = 0.  The number found is compared with the count
    (a mismatch would print a warning; none occurred in any run).
  - Integrators: adaptive DOP853 (rtol = atol = 1e-12; the reference) and a batched 4th-order Magnus
    propagator on a graded grid (geometric near the wall, where K ~ z^{1/12}), used for scans and the
    Kohn-Sham engine.
  - Wavefunctions: left and right (p, ln r) solutions matched at z_m, exact exponential tail beyond z_a,
    normalized Int_0^inf (f^2 + g^2) dz = 1 (Simpson + analytic tail).
  - Full 16-component check: the 16x16 system Psi' = T0 (m - i K T1 + i om T4) Psi with the notebook's T16
    (from the JSON), wall P Psi = Psi, integrated by a Magnus/matrix-exponential propagator on the 8-dim
    subspaces; the number of zero singular values of [Q_left | Q_right] is the multiplicity.

6.0 Setting (derived in section 2; implemented in waveguide.py section 11)
  Functional per 8-volume: W(sigma) = m0 sigma + (lam/2) sigma^2, mean field m(z) = W'(sigma(z)) = m0 + lam sigma(z),
  m0 = 1 H.  lam < 0 is attractive; in the homogeneous gas the gap equation m = m0 + lam sigma_KS(m) has a
  unique root because sigma_KS is increasing in m.
  How the hidden volume enters: the admissible modes are zero modes along x5..x7, normalized over the
  hidden COORDINATE volume V_hid; the 8-density per proper 7-volume carries 1/V_hid.  Choice: V_hid = 1/H^3
  (so lam also stands for the effective 5D coupling lam/V_hid).  With a4 = 0, the transverse coordinate
  volume equals the asymptotic proper one; N_s = number per unit coordinate observed 3-volume.
  Orbitals: for transverse momentum k (any direction; rotated onto x1, the spectrum depends on |k| only)
  and each positive level of either irrep, 4 degenerate states (2 blocks with J = +1, 2 with J = -1); a
  "band" is one such level family om_b(k), b = (irrep, Pruefer index).
  Scalar density of a block orbital: the Fock expectation of Psibar Psi in a J-eigenmode state is the
  Krein-weighted sum eta_u u^dag sigma16 u = u^dag bet u = |f|^2 - |g|^2 (derived and checked in 2.4);
  the number density is |f|^2 + |g|^2.  Because the transverse proper volume is q^3 p^3 = 1/Sin(z),
      sigma(z) = Sin(z) sum_b 4 Int d^3k/(2pi)^3 theta(occupied) (f^2 - g^2)_{b,k}(z),   n(z) likewise with (f^2 + g^2),
      E/A = sum_occ om + Int (W - sigma W') dz/Sin = sum_occ om + (|lam|/2) Int sigma^2/Sin dz,
  with Int d^3k/(2pi)^3 = (1/2pi^2) Int k^2 dk.  No-sea (the Dirac sea of negative levels is not in sigma),
  E_xc neglected.  Occupations: common Fermi level mu with N_s = sum_b (4/6pi^2)(kF_b^3 - k_lo,b^3); band
  thresholds k_lo refined by bisection on Delta(R(k), k) = j Pi; sigma from 16-point Gauss-Legendre in k
  per occupied interval with the orbitals computed at the nodes; Anderson mixing (5 steps, 0.5).
  Checks built in: N(check) = Int n dz/Sin (+ exact tails) reproduces N_s to 1e-8 in every iteration.

6.1 The author's mass term W = m0 sigma (lam = 0; m0 = -2M)
  The action is bilinear: the theory is FREE, the single-particle levels of section 4 are the EXACT spectrum
  and every many-body eigenstate is a Slater determinant of exact modes; no self-consistency is needed.
  Consequences [dev/waveguide_run_dft.log, DFT-a]:

    in the half-infinite geometry at vanishing density near the wall).  The wall levels are excited states.

    normalization (1e-5; replaced by Simpson), a wrong edge-branch identification at K >= 80 (fixed),
    a grid mismatch in the band-gap step, and shell-escaping of "\n" in two patches.
  - The notebook was rebuilt by another agent during this session (172 -> 217 Input cells); cells

    whose text that version of the script did not print; in the final run (the log shipped) no cell raised
    a message.  It was not identified.

Caveats (physics):
  - a4 is frozen (fixed x4, adiabatic); with a4 varying in x4 the plane wave e^{-i om x4} is not exact and
    the momentum redshifts as K_inf = k e^{a4}.  All numerics use a4 = 0.
  - Zero modes along x5..x7 (admissible sector) and along x2, x3 (the transverse momentum is rotated onto
    x1; the spectrum depends on |k| only).  V_hid = 1/H^3 enters only through sigma (and lam_4 = lam/V_hid).
  - The wall condition is a choice (self-adjoint extension); the results depend strongly on it (4.4).
    The covariant, flavour- and C-symmetric choices are MIT+ and MIT-; which one is "same-sign" depends on
    sign(m) (m = -2M for the author's mass term), so both are physically possible.
  - No-sea approximation (vacuum polarization of the negative-energy levels neglected / absorbed into W),
    E_xc neglected (Hartree mean field), local functional m(z) = W'(sigma(z)).
  - The Delta-SCF excited states are stationary configurations with constrained occupations, not
    eigenstates of an exact many-body Hamiltonian.

Open points (not done):
  - A grand-canonical treatment of the same-sign wall with a bulk fable density (then the wall bands
    at k > K_c are surface states of a filled bulk) was outside the specification and not done.
  - A constrained (position-fixed) KS iteration for the strong-coupling layer, to map E(z_c) self-
    consistently, was not done; only the rigid-shift upper bound of 6.4 was computed.
